The follicular phase is the first half of the menstrual cycle. It begins on the first day of your period and continues until ovulation occurs. This phase is all about preparing an egg for release.

## How Does the Follicular Phase Work?

The pituitary gland releases Follicle Stimulating Hormone (FSH), which prompts the ovaries to produce several follicles, each containing an immature egg. Usually, only one follicle matures fully. As it grows, it releases estrogen, which thickens the uterine lining.

## Real-World Example

In a cycle that lasts 32 days where ovulation happens on Day 18, the follicular phase lasts for the first 18 days. During the later part of this phase (after bleeding stops), a woman often feels a surge in energy and improved mood due to rising estrogen.

## Why is the Follicular Phase Important?

This phase sets the stage for ovulation and potential pregnancy. Variations in cycle length are almost always due to variations in the length of the follicular phase. Using [LunaCycle](/) helps you track when this phase transitions into ovulation.

## Follicular Phase vs Luteal Phase

| Feature | Follicular Phase | Luteal Phase |
| :--- | :--- | :--- |
| Timing | First half of cycle | Second half of cycle |
| Main Event | Egg maturation | Uterine preparation |
| Length | Highly variable | Relatively constant (11-17 days) |
