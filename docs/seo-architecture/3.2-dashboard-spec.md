# GSC + GA4 Integration Dashboard Spec

A custom Looker Studio (or similar) dashboard spec designed specifically for monitoring a programmatic micro-tool ecosystem.

## Data Sources
1. **Google Search Console (URL Impression & Site Impression tables)**
2. **Google Analytics 4 (GA4)**
3. Blended Data Key: Exact URL match.

## Dashboard Sections

### 1. The Breakout Board
**Purpose:** Identify tools gaining rapid traction.
- **Visual:** Bar chart showing Top 10 URLs by week-over-week impression growth (%).
- **Metrics:** Impressions (current week), Impressions (previous week), % Change.
- **Filter:** `URL contains /tools/`

### 2. The Optimization Queue (Low-Hanging Fruit)
**Purpose:** Find pages that rank but don't get clicked (Metadata issues).
- **Visual:** Scatter plot or Table.
- **Metrics:** Clicks, Impressions, CTR, Average Position.
- **Condition:** Impressions > 1000, Position < 15, CTR < 2%.
- **Action:** Rewrite the `seo-metadata.ts` template for the clusters containing these tools.

### 3. The Latent Potential Board
**Purpose:** Find topics Google thinks we are relevant for, but we don't have enough authority/exact-match content for yet.
- **Visual:** Table mapping Query to URL.
- **Metrics:** Impressions, Position.
- **Condition:** Impressions > 5000, Position between 15 and 50.
- **Action:** If the query is slightly different than the URL's purpose, build a new tool specifically for that query. If it's a perfect match, we need more internal links pointing to this URL.

### 4. Utility Engagement Monitor (GA4)
**Purpose:** Ensure users are actually using the tools (good for UX signals and Core Web Vitals).
- **Visual:** Table by URL.
- **Metrics:** Organic Sessions, Engagement Rate, Average Engagement Time.
- **Condition:** Sort ascending by Engagement Rate.
- **Action:** If a tool has high traffic but <20% engagement rate, the UI is likely broken, or it's too hard to use on mobile.

### 5. Content Decay Monitor
**Purpose:** Identify older informational guides that are losing traffic.
- **Visual:** Line chart plotting Impressions over a 6-month trailing window.
- **Filter:** `URL contains /guides/` AND Month-over-Month impressions are negative.
- **Action:** Refresh the guide with new statistics, add a new FAQ section, and update the "Last Modified" date in the sitemap.
