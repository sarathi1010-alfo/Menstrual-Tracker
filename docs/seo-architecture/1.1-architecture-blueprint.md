# Architecture Blueprint: LunaCycle Programmatic SEO Ecosystem

## 1. Project Overview & Requirements
- **Goal:** Reach 1,000+ indexed pages via a programmatic micro-tool ecosystem within 12 months.
- **Niche/Aesthetic:** Health & wellness (Cycle tracking, pregnancy calculations, ovulation tools), maintaining a calm, medical-neutral aesthetic.
- **Data Privacy:** 100% client-side data. No backend databases. Use `localStorage` exclusively.
- **Tech Stack:** Next.js (App Router), TypeScript, Tailwind CSS, Vercel/Cloudflare (Edge/Serverless).

## 3. SEO Constraints & Technical Specifications

### URL & Sitemap Architecture
- **Flat Paths:** Tools sit at `/tools/[slug]` or `/tools/[cluster]/[slug]` (e.g. `/tools/pregnancy/due-date-calculator`).
- **Sitemap Index:** The `src/app/sitemap.ts` file must serve an `<sitemapindex>` pointing to partitioned cluster sitemaps (e.g., `sitemap-core.xml`, `sitemap-pregnancy.xml`, `sitemap-cycle.xml`).
- **Scale Limits:** Each individual sitemap file is limited to 50,000 URLs or 50MB.

### Canonical & Metadata
- **Canonical Tags:** Every tool page must dynamically declare a `rel="canonical"` tag pointing exactly to its final destination URL to avoid parameter-based duplication.
- **Dynamic Metadata:** Title tags, descriptions, and OpenGraph variables are dynamically constructed using `src/lib/seo-metadata.ts` based on tool parameters.

### Schema Markup
- Every tool page must include a valid `SoftwareApplication` schema (specifically `HealthApplication` for LunaCycle) describing its utility.
- Educational hubs use `Article` or `FAQPage` schema.
- Data is injected natively into `<head>` or via Next.js Metadata API.

### Robots.txt Template
```txt
User-agent: *
Allow: /
Disallow: /api/
Disallow: /admin/
Disallow: /*?*   # Block URL parameters from indexing

Sitemap: https://www.lunacycle.com/sitemap.xml
```

## 4. Security & Performance
- Static Site Generation (SSG) applied to pure informational content.
- Server-Side Rendering (SSR) applied only if dynamic request parameters are necessary, otherwise fallback to SSG/ISR to ensure high Core Web Vitals (LCP < 2.5s).
- All calculation states live in `localStorage`; no database latency.
