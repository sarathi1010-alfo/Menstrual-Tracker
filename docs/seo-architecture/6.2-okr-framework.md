# OKR Framework: Phases 2-4

## Phase 2 (Months 4-6): Cluster Expansion & Data Gathering
**Objective:** Scale horizontal topical coverage and establish a reliable data feedback loop.
- **KR1:** Deploy 3 new tool clusters (e.g., Post-Partum, Hormonal Health, Fitness tracking) reaching 300 total tools.
- **KR2:** Achieve a >3% average CTR across all tools via `seo-metadata.ts` optimization.
- **KR3:** Reduce "Discovered - currently not indexed" pages to <10% of total URLs.
- **Anti-Goal:** Do not spend time heavily redesigning the UI components.
- **Leading KPIs:** Indexed pages, Crawl frequency.

## Phase 3 (Months 7-9): Authority Building & System Scaling
**Objective:** Transition from generic utility capture to semantic dominance via Hub page expansion.
- **KR1:** Write and deploy 15 long-form, high-EEAT informational Hub Guides.
- **KR2:** Achieve >500 daily organic clicks consistently (measured via GSC).
- **KR3:** Automate 100% of the cross-cluster internal linking using semantic tagging.
- **Anti-Goal:** Do not attempt to monetize the site yet. Traffic scale first.
- **Leading KPIs:** Impressions on Hub pages, Long-tail keyword count.

## Phase 4 (Months 10-12): Dominance and Optimization
**Objective:** Dominate the health/wellness utility niche and prepare for AI Answer Engine (SGE) extraction.
- **KR1:** Reach 1,000 indexed programmatic tools.
- **KR2:** Ensure 100% of tool pages have strict `FAQPage` and `SoftwareApplication` schema for AI retrieval.
- **KR3:** Average Engagement Time (GA4) increases to >45 seconds per tool page (proving utility).
- **Anti-Goal:** Do not launch completely unrelated verticals (e.g., finance calculators). Stick to the health/cycle/pregnancy entity graph.
- **Leading KPIs:** AI Overview citation appearances (via specialized GSC filtering), Return user percentage.
