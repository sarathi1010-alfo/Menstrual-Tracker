# Inter-Cluster Semantic Linking Strategy

While clusters (e.g., Cycle vs Pregnancy) isolate authority, cross-linking connects them into a broader Knowledge Graph for Google, establishing LunaCycle as an authority on the whole reproductive lifecycle.

## Cross-Cluster Link Map

### 1. Cycle Cluster ↔ Fertility Cluster
**Overlap:** A user tracking their cycle is often trying to pinpoint their fertile window.
- **Link:** `next-period-predictor` (Cycle) → `ovulation-calculator` (Fertility).
- **Anchor Text context:** "If you are using this prediction to plan for conception, check our [ovulation calculator] instead."
- **Link:** `safe-days-calculator` (Cycle) → `luteal-phase-calculator` (Fertility).

### 2. Fertility Cluster ↔ Pregnancy Cluster
**Overlap:** A user tracking ovulation succeeds and needs to know the resulting timelines.
- **Link:** `ovulation-calculator` (Fertility) → `due-date-calculator` (Pregnancy).
- **Anchor Text context:** "Once you have conceived based on this ovulation date, you can use our [due date calculator] to map out your pregnancy."
- **Link:** `implantation-calculator` (Fertility) → `conception-calculator` (Pregnancy).

### 3. Pregnancy Cluster ↔ Cycle Cluster
**Overlap:** Post-partum cycle return.
- **Link:** `trimester-calculator` (Pregnancy) → `next-period-predictor` (Cycle).
- **Anchor Text context:** "After your pregnancy journey, use our [period predictor] to help track the return of your natural cycle."

## Risk Mitigation
- **Diluting Focus:** Only link cross-cluster when the user journey logically bridges the two topics.
- **Implementation:** Do not rely purely on automated algorithms for cross-cluster links. Hardcode these specific transition links into the `pSeoData.json` under a `nextStepTool` property for maximum contextual relevance.
