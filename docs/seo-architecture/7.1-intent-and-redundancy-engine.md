# Search Intent & Semantic Redundancy Engine

Before aggressively scaling CycleHub's programmatic ecosystem to 1,000+ pages, we must safeguard our YMYL authority. Blind scaling leads to cannibalization, intent mismatch, and algorithmic penalties.

## 1. Search Intent Classification Engine
Every query in our backlog must be classified *before* generation. The UI, copy tone, and trust signals must adapt to the intent.

### Intent Categories for CycleHub:
| Intent Classification | User Mindset | UX & Architecture Requirement | Example Query |
| :--- | :--- | :--- | :--- |
| **Diagnostic** | Seeking calculation based on data | Focus on the Tool UI. Minimal friction. Fast math. | "pregnancy due date calculator" |
| **Informational** | Learning about their body | Focus on MDX Guides. Clear H2 hierarchies. | "how long does ovulation last" |
| **Emotional / Reassurance** | Anxious, seeking normalcy | Softer UX, stronger medical disclaimers, empathetic tone. | "why am I spotting at 5 weeks" |
| **Temporal** | Phase-specific tracking | Timeline visuals, step-by-step progress tracking. | "first trimester timeline" |

**Implementation:** Add an `intentClass` property to `pSeoData.json`. The Next.js templates will conditionally render different Trust Badges or Disclaimer components based on this class (e.g., heavy disclaimers for "Emotional", fast UI for "Diagnostic").

## 2. Semantic Redundancy Detection System
YMYL domains are heavily penalized for shallow variants (doorway pages). We must score "intent similarity" before launching a new tool.

### The Overlap Test (Pre-Generation Check)
When evaluating a new keyword (e.g., "Menstrual Cycle Tracker" vs. "Period Tracker"):
1. **Search the query in Google.**
2. Look at the top 3 ranking URLs for *both* queries.
3. If 2 or more of the URLs are the **exact same page**, Google treats these queries as having identical intent.
4. **Action:** Do NOT build a new page. Instead, add the new keyword as an H2 or FAQ inside the existing tool page.

### The Cannibalization Sweep (Post-Launch Check)
Run this GSC filter monthly:
- Look for multiple CycleHub URLs ranking for the exact same query in Positions 10-30.
- If two URLs are competing for the same query, they are cannibalizing each other's authority.
- **Action:** Merge the content of the weaker page into the stronger page, and implement a 301 Redirect.
