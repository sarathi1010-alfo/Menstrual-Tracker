# Cluster Architecture Designer: LunaCycle

To establish semantic topical authority, we must structure our programmatic tools into tightly knit clusters using a Hub-and-Spoke model.

## Core Architecture Principle
Google must easily understand that LunaCycle is not just a collection of random calculators, but a comprehensive health tracking entity. We do this via dense internal linking where the Hub aggregates authority and distributes it to the Spokes (tools).

## Cluster Map 1: The "Fertility & Ovulation" Cluster

### 1. The Hub Page
- **URL:** `/blog/understanding-ovulation`
- **Type:** Long-form MDX guide (SSG)
- **Role:** The ultimate guide to tracking ovulation, answering high-level intent ("how to get pregnant", "when do I ovulate").
- **Linking:** Links out to *every* tool in the Fertility cluster.

### 2. The Spoke Tools (Programmatic)
These tools rank for exact-match utility keywords. Every tool links back to the Hub, and to 2 sibling tools.

1. **Ovulation Calculator** (`/tools/ovulation-calculator`)
   - Utility: Predicts ovulation day based on cycle length.
2. **Safe Days Calculator** (`/tools/safe-days-calculator`)
   - Utility: Estimates non-fertile window.
3. **Implantation Bleeding Calculator** (`/tools/implantation-calculator`)
   - Utility: Calculates date of potential implantation based on ovulation date.
4. **Luteal Phase Calculator** (`/tools/luteal-phase-calculator`)
   - Utility: Determines luteal phase length based on cycle data.

## Cluster Map 2: The "Pregnancy Timing" Cluster

### 1. The Hub Page
- **URL:** `/blog/pregnancy-timeline`
- **Type:** MDX Guide
- **Role:** Broad timeline of pregnancy milestones.

### 2. The Spoke Tools (Programmatic)
1. **Due Date Calculator** (`/tools/due-date-calculator`)
   - Math: LMP + 280 days.
2. **Conception Date Calculator** (`/tools/conception-calculator`)
   - Math: Due Date - 266 days.
3. **Trimester Calculator** (`/tools/trimester-calculator`)
   - Math: Breaks down current date into trimester phases based on LMP.

## Semantic Entity Mapping
To ensure Google recognizes the entity relationships, our JSON-LD schema across these clusters must share common `about` and `mentions` properties referencing Wikidata entities (e.g., Menstrual Cycle, Ovulation).
