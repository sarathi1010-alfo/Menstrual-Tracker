# Weekly SEO Review Framework

This SOP defines the weekly rhythm for analyzing Google Search Console (GSC) and Google Analytics 4 (GA4) data to drive LunaCycle's programmatic SEO roadmap.

## The 5 Strategic Questions

### 1. Which tools are breaking out?
- **GSC Filter:** Compare Last 7 Days vs. Previous 7 Days. Filter by `URL contains /tools/`. Sort by Impressions (Delta).
- **Decision:** If a tool's impressions spiked by >50%, it has momentum. Add internal links pointing TO this tool from the homepage and cluster hub to accelerate indexing/ranking.

### 2. Which pages have high impressions but low CTR?
- **GSC Filter:** Last 28 Days. Impressions > 500. CTR < 2%. Position < 15.
- **Decision:** The page ranks reasonably well but the title/description isn't compelling. Update `seo-metadata.ts` to generate a better title template for this tool's cluster. Test for 2 weeks.

### 3. Which keywords have high impressions but poor ranking? (Latent Potential)
- **GSC Filter:** Last 28 Days. Impressions > 1,000. Position between 15 and 50.
- **Decision:** We are semantically relevant but lack topical authority or exact-match content. Look at the specific queries. Do we need to build a new tool specifically for that query, or add an FAQ to an existing tool?

### 4. Which pages have impressions but zero clicks? (Intent Mismatch)
- **GA4/GSC Filter:** Pages with >1,000 impressions but 0 clicks.
- **Decision:** Google is surfacing our URL for irrelevant queries (e.g., we rank for "pregnancy test online" but our tool is a "pregnancy due date calculator"). Update the H1 and Meta Description to aggressively clarify what the tool *actually* does to fix the intent mismatch.

### 5. What new tools should be built based on keyword data?
- **GSC Filter:** Sort Queries by Impressions. Look for long-tail variations of existing tools (e.g., if "ovulation calculator" is popular, search for queries containing "calculator" that we *don't* have pages for yet).
- **Decision:** Add these to the `pSeoData.json` backlog for the next development sprint.

## Weekly Execution Checklist
- [ ] Pull data for the 5 questions above.
- [ ] Update `seo-metadata.ts` for at least 1 cluster (Title/Description tweaks).
- [ ] Add at least 5 new tool ideas to the backlog based on query expansion.
- [ ] Check Indexing Status: Have any 5xx errors spiked?
