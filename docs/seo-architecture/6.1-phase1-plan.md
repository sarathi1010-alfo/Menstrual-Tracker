# Phase 1 Execution Plan (Months 1-3)

**Goal:** Indexing Domination. Establish the baseline infrastructure and get the first 100 pages crawled, indexed, and appearing in GSC.

## Week 1-2: Infrastructure Build
- **Owner:** Engineer
- **Tasks:**
  - Build the 5 core component templates (`Calculator.tsx`, `Converter.tsx`, etc.).
  - Implement `sitemap.ts` index splitting.
  - Implement dynamic `rel="canonical"` and `seo-metadata.ts` pipeline.
  - Setup GitHub Actions deployment pipeline.

## Week 3-4: The "Fertility" Cluster Land Grab
- **Owner:** SEO / Engineer
- **Tasks:**
  - Write the long-form Hub page: "The Complete Guide to Tracking Ovulation".
  - Use the LLM keyword expansion script to generate the first 30 tools for `pSeoData.json`.
  - Deploy. Run the Indexing Audit Checklist.

## Week 5-8: The "Pregnancy" Cluster Land Grab
- **Owner:** SEO / Engineer
- **Tasks:**
  - Write the Hub page: "Pregnancy Timeline & Milestones".
  - Generate 30 pregnancy-related math/timeline tools.
  - Inject cross-cluster links bridging Cycle tracking to Pregnancy.
  - Deploy. Run Audit.

## Week 9-12: The Data Feedback Loop Begins
- **Owner:** SEO / Analyst
- **Tasks:**
  - By Month 3, we will have ~90 days of GSC data on the first 30 tools.
  - Execute the first **Weekly Review SOP**.
  - Build the Looker Studio Dashboard.
  - Run the Pruning Framework: Are any tools flatlining?
  - Update `seo-metadata.ts` templates based on CTR data.

## Phase 1 Exit Criteria
1. Architecture is 100% stable (No 5xx errors, 0 hydration errors).
2. 100 Tools deployed.
3. >80% of tools indexed by Google (Verify in GSC Coverage Report).
4. Automated sitemap submission pipeline is functioning.
