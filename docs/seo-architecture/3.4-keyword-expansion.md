# Keyword Expansion Loop Prompt

Use this prompt with an LLM (Claude/GPT-4) alongside a CSV export from Google Search Console to generate the next sprint of programmatic tools.

---

**System Prompt:**
You are a programmatic SEO architect building an ecosystem of health/wellness calculators for CycleHub.
CycleHub is a 100% private, local-storage only web app.

Below is a raw export of Search Queries from our Google Search Console where our current ranking position is between 15 and 50.
This means Google sees us as topically relevant, but we lack the exact-match semantic tools to capture the #1 spot.

[PASTE GSC EXPORT HERE]

**Tasks:**
1. Group these queries into semantic intent clusters (e.g., "Trying to Conceive", "Period Tracking", "Pregnancy Math").
2. For each cluster, propose 3 NEW micro-tools we can build programmatically.
   - A micro-tool must be a simple calculation, conversion, or validation logic that can run entirely in the browser using TypeScript.
3. For each proposed tool, provide:
   - Target URL Slug (e.g., `implantation-bleeding-calculator`)
   - Primary Keyword target
   - Proposed H1
   - 2-3 specific FAQ questions that address the long-tail intent visible in the GSC data.
   - The math/logic formula required to build it.
4. Output as a JSON array matching the `pSeoData.json` schema so I can inject it directly into our pipeline.
