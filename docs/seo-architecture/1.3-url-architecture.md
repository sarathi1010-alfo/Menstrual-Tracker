# URL & Internal Link Architecture: LunaCycle Ecosystem

## 1. URL Architecture Rules
- **Subfolders > Subdomains:** All tools live under a unified domain (e.g., `lunacycle.com/tools/...`) to consolidate link equity.
- **Flat Depth:** URLs must never exceed 3 levels deep (`/tools/[cluster]/[tool]`).
- **Semantic Clarity:** Slugs must exactly match the primary keyword target. No random strings or IDs.

## 4. Internal Linking Logic (TypeScript)
Every page must link to its hub, and to 2-3 semantically related sibling pages.

```typescript
// src/lib/internal-links.ts

interface ToolMetadata {
  slug: string;
  cluster: string;
  title: string;
  relatedTags: string[];
}

export function generateInternalLinks(
  currentTool: ToolMetadata,
  allTools: ToolMetadata[],
  limit: number = 3
): ToolMetadata[] {
  // 1. Prioritize tools in the exact same cluster
  let related = allTools.filter(t =>
    t.cluster === currentTool.cluster && t.slug !== currentTool.slug
  );

  // 2. If we need more, find tools sharing semantic tags across clusters
  if (related.length < limit) {
    const crossClusterMatches = allTools.filter(t =>
      t.cluster !== currentTool.cluster &&
      t.relatedTags.some(tag => currentTool.relatedTags.includes(tag))
    );
    related = [...related, ...crossClusterMatches];
  }

  // 3. Return a deterministic slice based on the current tool's slug (to prevent link churn)
  // In production, use a seeded random or consistent hash. Here we just take the first N.
  return related.slice(0, limit);
}
```
