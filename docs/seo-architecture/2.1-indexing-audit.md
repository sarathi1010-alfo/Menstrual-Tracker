# Indexing Audit Checklist

## Purpose
Run this checklist after every batch deployment of new programmatic tools to ensure zero indexing failures.

## Known Failure Modes
- Accidental `noindex` tags injected by misconfigured `<head>` components.
- React hydration errors or JavaScript blocking that prevents Googlebot rendering.
- Missing or broken `rel="canonical"` tags.
- Internal link orphans (new tools not added to the `pSeoData.json` or cross-linking widgets).
- Duplicate content flags from URL parameter variants.

## Pre-Launch & Post-Deploy Checklist

| Check | How to Test | Pass Criteria | What to Fix If Failing |
| :--- | :--- | :--- | :--- |
| **Noindex Tag Check** | View Source (Ctrl+U) on production URL. | Must NOT contain `<meta name="robots" content="noindex">`. | Check `src/lib/seo.ts` defaults and `noIndex` prop in metadata config. |
| **Canonical Tag** | View Source. Look for `<link rel="canonical" href="...">` | Must point exactly to the flat URL (e.g., `.../tools/ovulation-calculator`). No URL parameters. | Update `absoluteUrl` logic in `seo.ts` or the page's `metadata` export. |
| **JavaScript Rendering** | Disable JS in browser / Use GSC "Test Live URL" > View Tested Page. | Core calculation shell, H1, and FAQ text must be visible in HTML without JS. | Move content out of `"use client"` wrappers; ensure SSG generation worked. |
| **Sitemap Inclusion** | Check `/sitemap/tools.xml` | The new tool's exact URL must be present. | Ensure the tool is added to `src/data/pSeoData.json` and build ran successfully. |
| **Internal Linking** | Inspect cluster hub page and the Global Related Tools Widget. | Tool must be linked from at least 3 other internal pages. | Update cross-linking logic in `RelatedToolsWidget.tsx` or update the hub markdown. |
| **Server Response** | Look at Network tab in DevTools on hard refresh. | Status 200, Document TTFB < 500ms. | If slow, check if page is falling back to SSR instead of SSG (remove dynamic functions). |
| **Schema Validation** | Paste URL into Google Rich Results Test. | Must pass "SoftwareApplication" (or specific Health App) and "FAQPage" without errors. | Fix JSON syntax in `SchemaMarkup.tsx` or missing required fields in `pSeoData.json`. |
