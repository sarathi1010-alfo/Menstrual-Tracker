# LUNACYCLE WEEKLY CONTENT ENGINE: STRATEGIC PLAN

This document defines the repeatable content system for LunaCycle to build semantic authority in the privacy-first menstrual tracking niche.

## 1. THE REPEATABLE WEEKLY TEMPLATE SYSTEM

### Template A – Cluster/Pillar Article (700-1000 words)
- **H1:** `[PRIMARY_KEYWORD]`: Complete Guide for `[TARGET_AUDIENCE]` in 2026
- **Snippet:** 30-word intro definition (for Google AI Overview)
- **H2:** Why `[PRIMARY_KEYWORD]` Matters for `[AUDIENCE/USE_CASE]`
- **H2:** How to `[ACTION]` with `[PRIMARY_KEYWORD]` (step-by-step)
- **AEO Box:** 5 Key Takeaways (bullets)
- **AEO Box:** FAQ Section with FAQPage Schema

### Template B – Programmatic Comparison Page (500-700 words)
- **H1:** `[ENTITY_A]` vs `[ENTITY_B]`: Which Period Tracker is Better for `[USE_CASE]`?
- **Quick Verdict:** 1-sentence AI summary
- **Comparison Table:** Features, `[ENTITY_A]`, `[ENTITY_B]`, Winner
- **AEO Box:** "Best Pick for [Scenario]"

### Template C – Micro-Answer Page (300-500 words)
- **H1:** What is `[CYCLE_TERM]`? (direct question format)
- **Definition:** 40-60 word definition
- **H2:** How Does `[TERM]` Work?
- **H2:** `[TERM]` vs `[RELATED_TERM]` (comparison table)

### Template D – Pillar Page (3000-7000 words)
- **H1:** The Ultimate 2026 Guide to `[BROAD_TOPIC]`
- **Executive Summary:** 200 words for AI Overviews
- **Table of Contents:** Jump links to chapters
- **AEO Box:** Statistical Data Table

### Template E – Use Case / Audience Guide (600-800 words)
- **H1:** Cycle Tracking for `[AUDIENCE]`: The Complete 2026 Guide
- **Section:** Why it matters for `[AUDIENCE]`
- **Section:** Key features in LunaCycle for `[AUDIENCE]`
- **AEO Box:** Quick Reference Table (Audience → Key Features → Tips)

### Template F – Condition/Health Deep-Dive (600-800 words)
- **H1:** The Complete Guide to `[CONDITION]` and Cycle Tracking
- **Section:** How `[CONDITION]` affects the cycle
- **Section:** How tracking helps manage `[CONDITION]`
- **AEO Box:** Reference Table (Condition → Symptoms → Cycle Impact)
